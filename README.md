# GN-AOI

> Gas & Navigation - Automotive Optimization Interface

GN-AOI は、燃費記録とコスト分析に特化した\
軽量・ローカル完結型の燃費管理Webアプリです。

CSVベースでデータを管理し、\
入力のしやすさと分析のしやすさを両立しています。

------------------------------------------------------------------------

## 概要

GN-AOI は以下を重視して設計されています。

-   DBを使わない（CSVベース）
-   ローカル環境で完結
-   入力の手軽さ
-   可視化・分析のしやすさ

------------------------------------------------------------------------

## 主な機能

### 記録管理

-   給油記録の登録・編集・削除
-   CSVベースのデータ管理
-   入力UX最適化（選択項目のみ前回値補完）

### サマリー

車両・走行 / 燃費 / 給油・費用の3カテゴリで表示

### 可視化

-   燃費推移グラフ
-   平均燃費ライン
-   燃料単価推移グラフ
-   期間フィルタ（全期間 / 1年 / 90日 / 30日）

### 分析機能

-   異常値検知（±20%）
-   直近5回平均燃費
-   月別給油集計（年別折りたたみ）

### エクスポート

-   記録CSV（生データ）
-   月別給油集計CSV（分析用）

------------------------------------------------------------------------

## 設計方針

-   CSVベース設計（DB不使用）
-   ローカル完結
-   既存データ非破壊
-   表示用派生データによる拡張

------------------------------------------------------------------------

## 技術構成

-   Flask
-   Chart.js（ローカル配置）
-   Vanilla JS / CSS

------------------------------------------------------------------------

## データ仕様

date,time,fuel_l,price_yen,trip_km,odd_km,full,distance_mode,fuel_type,note

------------------------------------------------------------------------
