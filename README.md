# GN-AOI

Automotive Optimization Interface

CSVベースで動作する、軽量な燃費管理Webアプリです。
データベース不要で、シンプルに使えることを重視しています。

---

## 特徴

* Flaskで動作するシンプルな構成
* データはCSVで管理（DB不要）
* 1車両1CSVの分かりやすい設計
* スマホ操作を前提としたUI
* ダークモード対応

---

## できること

* 車両の追加・削除
* 給油記録の追加・削除
* 燃費の自動計算
* サマリー表示

  * 総走行距離
  * 平均燃費
  * 最高燃費
  * 最低燃費
  * 直近燃費
* CSVインポート / 初期化

---

## 起動方法

### 1. 仮想環境の作成

python -m venv .venv

### 2. 仮想環境の有効化

source .venv/bin/activate

### 3. パッケージのインストール

pip install -r requirements.txt

### 4. アプリの起動

python run.py

---

## アクセス方法

アプリは以下のアドレスで起動します。

* ローカル環境
  http://127.0.0.1:5013

* LAN内の他端末から
  http://<サーバーのIPアドレス>:5013

※本アプリは 0.0.0.0 で起動しており、同一ネットワーク内からアクセス可能です。

## 初期設定

本リポジトリには個人データは含まれていません。
初回起動後、以下を行ってください。

1. Settings タブを開く
2. 車両を追加する
3. 必要に応じて初期ODD距離を入力する

---

## 使い方

### 車両の追加

* Settings タブを開く
* 車両名を入力して追加

### 記録の追加

* Records タブを開く
* 給油量・価格・距離を入力

区間距離（trip）または積算距離（odd）のどちらかで記録できます。
不足している値は、前回記録をもとに自動補完されます。

---

## 総走行距離について

総走行距離は以下で計算されます。

初期ODD距離 + 記録の区間距離合計

車両追加時に初期ODD距離を設定することで、
記録開始前の走行距離も含めた値を表示できます。

---

## インポートについて

インポート機能は、GN-AOIでエクスポートしたCSV形式のみ対応しています。

* 外部アプリのCSV
* 旧形式のCSV

には対応していません。

不正な形式のCSVは、安全のため取り込みを中止します。

---

## データ構造

* 車両情報: instance/vehicles.json
* 記録データ: instance/records/*.csv

すべてのデータはローカルに保存されます。
